# Synthetic demo data

`DEMO0001.csv`-`DEMO0004.csv` are **synthetic** SCADA-like time series (30-minute cadence, ~83 days
each), generated by [`generate_synthetic_demo.py`](generate_synthetic_demo.py) with a fixed random
seed. They follow the same column schema as the real EVN telemetry used in the paper (see
[`../docs/data_schema.md`](../docs/data_schema.md)) but are **not** derived from, subsampled from,
or in any way related to real substation data -- they exist only so the code in this repository can
be run and inspected end-to-end without access to the proprietary real dataset.

Regenerate them at any time with:

```bash
python generate_synthetic_demo.py
```

Numbers produced by running the experiment scripts against this synthetic data are **not**
meaningful forecasting results and should not be compared with the paper's reported numbers -- for
that, see the real, non-confidential aggregated results in [`../results/`](../results/), which were
computed on the actual EVN telemetry.

An optional `weather/<CODE>.csv` subfolder (not included) can hold per-meter ERA5-style weather
data for `experiments/weather_ablation/`; see `../src/features/fetch_weather.py` for the fetch
pipeline used in the paper.
